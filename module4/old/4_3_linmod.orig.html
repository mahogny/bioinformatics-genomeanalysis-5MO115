Recap: Linear least squares

Introduction: If you have 4 data points and want to fit a line through them, you cannot do it using linear equation systems alone - it assumes that all 4 points all are neatly on the line, but the random noise added during measurement prevents it from being the case. Instead, we need to combine the linear model with the power of statistics to find the best possible solution to the equations. Handle other statistical distributions using (R)STAN

Introduction: The normal distribution turns out to have nice mathematical properties, which is a reason it is commonly used. However, sequencing data is discrete, i.e, you have N molecules, and N is never a negative number. Thus bioinformaticians these days frequently need to use some type of Poisson distribution.
